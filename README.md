# Muhammad Haider Ali | Cybersecurity Portfolio

A single-page, dark, terminal-inspired portfolio for an aspiring cybersecurity specialist focused on networking and system administration.

# Overview

Plain HTML, CSS and JavaScript in one index.html file. No build step, no frameworks. It is mobile-first and hosted free on GitHub Pages.

# Features
Dark 
#0a0a0c theme with crimson 
#ff2a2a accents and a subtle grid
Matrix-style background rain and a typing terminal effect
Framed profile picture styled as a terminal window
Scroll-triggered slide and fade animations, glowing hover cards
Responsive layout with a mobile menu and no horizontal overflow
Contact form that delivers to email through Formspree, with success and error messages and a spam honeypot
Footer socials: LinkedIn, X, Instagram and a copy-to-clipboard Discord handle
Respects prefers-reduced-motion
Tech Stack

HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript, Google Fonts (Inter, JetBrains Mono), Formspree, GitHub Pages.

# Quick Setup
Put index.html and photo.jpg in the root of your repository.
Contact form: create a free form at formspree.io using ibnwaryam@gmail.com, copy its form ID, and replace YOUR_FORM_ID in the FORM_ENDPOINT line near the bottom of index.html. Confirm the email Formspree sends you.
Photo: replace photo.jpg with your own picture (same file name).
Publish: in the repository go to Settings → Pages, choose Deploy from a branch, branch main, folder / (root), then Save.
Your site will be live at https://<username>.github.io/<repository>/ within a couple of minutes.
